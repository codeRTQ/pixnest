修复合并按钮的真正原因：JS 里写了 Python 语法 + 改为两步确认

① 真凶：mergeGroup 里写了 '、'.join(from)（Python 写法），JS 应写 from.join('、')
   运行时报 TypeError: "、".join is not a function，confirm 根本没弹出。
   这类错误 node --check 抓不到（语法合法、运行时才炸）——
   刚加的 window.onerror 弹窗立刻把它暴露出来了。
   已全量排查 5 个后台页面渲染后的 JS，无其它 Python 写法残留
   （.append( 命中的是 FormData.append，正常）。

② 合并/删除标签改为「两步确认」按钮，不再依赖浏览器 confirm：
   第一次点 → 按钮变「确认合并」并提示；5 秒内再点一次才执行。
   规避「浏览器拦截弹窗导致 confirm 永远返回 false → 点了像没反应」。

③ 实测端到端：真实点击两次 → 标签 101→100→99，
   校服→制服、泳池边→泳池 合并成功，相近组归零，页面自动刷新。
